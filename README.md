# CLC Cure Life Care — product catalogue

GitHub Pages site for the official CLC catalogue.

## Upload these files to the repo

Replace the empty `index.html` on GitHub with this folder:

```
index.html
images/
  logo.png
  hero-bg.jpg
  about.jpg
  ... (keep the whole images folder)
```

### Fastest way (phone or computer)

1. Open https://github.com/digeshwarsahu7879-spec/CLC
2. Delete the current empty `index.html` (or overwrite it).
3. Click **Add file → Upload files**.
4. Upload `index.html` **and** the full `images` folder.
5. Commit to the `main` branch.
6. Wait 1–2 minutes, then open:
   https://digeshwarsahu7879-spec.github.io/CLC/

Do not paste photos into the HTML as base64. Keep photos in the `images` folder.
